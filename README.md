# 强兼互联 · QiangJian Connect

使用中间兼容层，探索澎湃 OS 4（HyperOS 4）与 ColorOS 17 设备之间的互联互通。

项目将两端的设备发现、连接管理和互联能力转换为统一接口，减少业务逻辑对厂商实现的依赖。

> 当前处于仓库初始化阶段，仅包含项目结构和设计文档。尚未实现设备连接，也未完成任何机型或系统版本的兼容验证。

## 目标与范围

- 为两端建立独立适配器，对外提供统一的设备与能力模型。
- 优先验证设备发现、配对和小文件传输的最小闭环。
- 后续按实机验证结果评估剪贴板同步、通知协同等能力。
- 接口、协议、运行位置和开发语言在前期验证后确定；上述能力均为规划。

## 设计概览

```text
澎湃 OS 4 设备                                  ColorOS 17 设备
      │                                               │
      └── HyperOS 适配器 ── 统一兼容层 ── ColorOS 适配器 ──┘
                                 │
                          传输接口与会话管理
```

图示表示逻辑分层，不预设兼容层运行在手机、电脑还是独立桥接设备上。

## 开发路线

1. **接入验证**：记录实际设备、完整系统版本、可用接口、协议与权限要求，确定兼容层的运行位置。
2. **最小闭环**：实现双方发现、用户确认配对、小文件双向传输和断开连接。
3. **能力扩展**：逐项评估剪贴板同步、通知协同等能力，保留不支持时的明确反馈。
4. **稳定性验证**：覆盖断网、重连、权限撤回、版本差异和后台运行限制。

## 开始开发

```sh
git clone https://github.com/tycykp/qiangjian-connect.git
cd qiangjian-connect
```

本仓库为私有仓库，克隆需要对应的 GitHub 访问权限。当前没有构建、运行或自动化测试入口。

先阅读[架构设计](docs/architecture.md)和[兼容性记录](docs/compatibility.md)。新增适配前，先记录实机证据，再确定接口与实现方案。

已下载核对官方 tag 和 Maven 发布物。API 仅 compileOnly，APK 不内置框架实现。未使用旧 Xposed API；JNI 是标准 JNI crate 0.21.1，没有虚构 Rust libxposed 绑定。本版 autoHotReload=false，更新需重启目标进程。

[LSPosed 官方频道](https://t.me/s/LSPosed?before=327)的 v2.1.0 公告列出 API 102 和 Android 17 QPR1 Beta 4；v2.1.1 列出 Android 17 服务连接修复。这证明存在框架支持版本，不证明上述 OEM ROM 实际稳定。旧 GitHub v1.9.2 的 Android 14 范围不能替代新公告。

框架不作为构建依赖下载或安装。后续实机已核实：小米现有 LSPosed 2.2.1 / 7940、一加现有 LSPosed 2.2.1-it / 7919，lspctl 与模块 getApiVersion() 均为 102，装载成功；详见 [实机记录](runtime-validation-20261108.md)。本轮未替换框架，也未取得框架发行 ZIP 的摘要。

AGP 固定 9.4.1、Gradle 9.7.1、SDK/build-tools 37.0.0、NDK 29.0.14206865；[AGP 9.4 官方发行说明](https://developer.android.google.cn/build/releases/agp-9-4-0-release-notes?hl=en)确认 API 37 支持。Rust 固定本机已有 nightly-2026-08-01（rustc 1.99.0-nightly/ad3d0bc14），不是滚动 nightly。所有 Rust 传递依赖记录于 Cargo.lock，Gradle 依赖摘要记录于 verification-metadata.xml。
